# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in this provider, please **do not** open a public issue.

Instead, please send an email to the maintainer:
`devops@valoriz.com`

Please include:
- A description of the vulnerability.
- Steps or a minimal Terraform configuration to reproduce the issue.
- Potential impact.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch release.
